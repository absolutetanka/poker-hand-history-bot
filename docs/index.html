How it works

Set up in under a minute.

1

Add the bot

Click Add to Discord and pick your server.

2

Pick a channel

Run /setup add #channel, and every hand posted there gets formatted automatically.

3

Post a hand

Type it, send a voice note, or use /hand in any channel.

Built for hand review

Follows the conventions used on poker forums and in study groups.

Standard notation

Cards like Ks3h, K3o and K94r, and positions like CO and BTN. Ready to paste into solvers.

Pot on every street

Calculated from the action in big blinds, and only shown when every bet is known.

Voice notes

Talk through the hand instead of typing it. It's transcribed and formatted the same way.

No guessing

Anything you left out (stacks, sizes, suits) is flagged as Missing, never made up.
